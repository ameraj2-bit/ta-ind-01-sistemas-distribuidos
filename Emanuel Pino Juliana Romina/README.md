# TA-IND-01 — Análisis crítico de Redis y comparación con Valkey

## Datos del trabajo

- **Actividad:** TA-IND-01
- **Tema principal:** Redis
- **Sistema de comparación:** Valkey

## Objetivo general

Analizar críticamente a Redis como sistema distribuido y compararlo con Valkey, examinando sus arquitecturas, propiedades y comportamiento ante distintos escenarios.

## Descripción

Se investigarán los conceptos de sistemas distribuidos presentes en Redis y Valkey, incluyendo transparencias, CAP y PACELC, modelos de comunicación y tolerancia a fallos. También se preparará un experimento reproducible para observar aspectos de su funcionamiento y fundamentar una postura crítica. Los resultados y las referencias se incorporarán una vez verificados.
