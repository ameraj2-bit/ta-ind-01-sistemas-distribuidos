## Instrucciones de compilación

- **Compilador:** pdfLaTeX con biber para la bibliografía.
- **Archivo principal:** `informe/main.tex`
- **Dependencias:** TeX Live (o MiKTeX) con los paquetes `babel` (español), `graphicx`, `booktabs`, `hyperref` y `biblatex`.

Desde la carpeta `mera-jumbo-allison/informe/`, ejecutar en este orden:

```bash
pdflatex main.tex
biber main
pdflatex main.tex
pdflatex main.tex
```
